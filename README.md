# Retail Analytics Platform

An end-to-end data engineering project built with free, open-source tools.

## Stack
| Layer | Tool |
|---|---|
| Ingestion | Airbyte (Docker) |
| Warehouse | DuckDB |
| Transformation | dbt Core |
| Orchestration | Prefect |
| BI | Metabase (Docker) |
| Infra | Docker Compose + GitHub Actions |
